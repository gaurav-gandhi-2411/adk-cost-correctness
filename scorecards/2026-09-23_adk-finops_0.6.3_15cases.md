exactly) — commit `38cbad874a420f4a41ba56efd740e1d143aa6e1f` ("fix(plugin): skip partial LlmResponse chunks
during SSE streaming (#3)"). All other verdicts are unchanged:

- **C1_unknown_model still FAILs.** Commit `d43d8b247aa09c7815c80090960f5b95ab614a9c` adds a one-time
  logged/printed warning and marks the internal rate `is_fallback=True`, but the run's reported
  `total_cost_usd` still includes the fallback dollar figure unflagged — the scoring rule fails ANY
  reported figure for a genuinely unpriceable model, warned or not (see `docs/SCORING.md`).
- **C4_double_registration still FAILs.** Commit `f0569737a3ebd91dbe4efd219817a312db9f8d78` is a
  README-only note advising against dual registration; there is no runtime detection, warning, or refusal
  in the code, so the callback still fires twice and the total is still 2.00x.
- **M2_claude_opus_5 still FAILs**, same fallback-pricing mechanism as C1 (not separately filed).
